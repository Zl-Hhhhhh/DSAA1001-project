## 处理规则

- 原始 CSV 以 gzip 保存；保留全部 17 个字段，包括本次检查结果和违规描述。
- 历史表保留无 Pass/Fail 判断的记录。带标签表仅保留 Fail / Pass / Pass w/ Conditions，不包含 results、violations 或 location。
- 日期明确按 MM/DD/YYYY 解析并输出 YYYY-MM-DD；编号和邮编作为字符串处理。
- 类别只清理首尾/连续空白并统一大小写，不做未经证据支持的拼写合并。
- 缺失 facility_type / risk / inspection_type 使用 UNKNOWN；不推测缺失州名、城市或邮编，不做全数据统计填补。
- 仅移除同一 Inspection ID 的完全重复记录；相同 ID 内容冲突则停止。重复店铺访问及同日检查均保留。
- 无效/为 0 的许可证不作为共同店铺键；回退键需要后续 EDA 核查。同一许可证跨地址不能自动视为可靠的唯一店铺。
- 坐标仅校验全球合法数值范围；未筛掉郊区记录，未判断坐标是否确实对应地址。
- 仅生成静态/日历候选变量；尚未构造历史结果特征、划分训练集或训练模型。
- 历史特征必须使用严格早于当前检查日期的记录；同日先后未知，不得借 Inspection ID 推断发生顺序。
- 官方元数据提示 2018-07-01 检查程序变更；后续 EDA 应考察其影响。当前快照还可能有上报延迟及回溯修订。
