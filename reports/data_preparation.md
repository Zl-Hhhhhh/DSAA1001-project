## 处理规则

- 原始 CSV 以 gzip 保存；保留全部 17 个字段，包括本次检查结果和违规描述。
- 历史表保留全部结果类型。带标签表保留 Fail / Pass / Pass w/ Conditions，并移除 results、violations 和 location。
- 日期明确按 MM/DD/YYYY 解析并输出 YYYY-MM-DD；编号和邮编作为字符串处理。
- 类别清理首尾/连续空白并统一大小写；拼写合并须有对应关系的证据。
- 缺失 facility_type / risk / inspection_type 使用 UNKNOWN；其余缺失值保留，由后续训练流程处理。
- 仅移除同一 Inspection ID 的完全重复记录；相同 ID 内容冲突则停止。重复店铺访问及同日检查均保留。
- 许可证缺失、无效或为 0 时，使用名称与地址等信息匹配。店铺键属于初步匹配，许可证跨地址和回退匹配需核查。
- 坐标校验全球合法数值范围；郊区记录保留，坐标与地址的一致性需另行核查。
- 准备脚本生成静态和日历候选变量；历史特征由 ass2_features.py 构造。
- 历史特征只使用检查日前的记录；同日访问统一按日期分组，结果从次日起可用。
- 官方元数据提示 2018-07-01 检查程序变更；后续 EDA 应考察其影响。当前快照还可能有上报延迟及回溯修订。
